# Retail Sales Performance Analysis

This project analyzes synthetic retail transaction data to understand revenue trends, product performance, customer behavior, and regional sales results.

## Business problem

A retail company wants to identify which products, regions, and time periods drive revenue, and where sales performance can be improved.

## Tools used

- Python
- pandas
- Matplotlib
- SQL
- KPI reporting

## Dataset

The project uses a synthetic dataset of 8,000 retail transactions containing:

- Order ID
- Order date
- Customer ID
- Product category
- Product name
- Region
- Quantity
- Unit price
- Revenue
- Payment method

The dataset is generated by `data/generate_data.py`, making the project reproducible.

## Analysis approach

1. Generate and inspect the retail sales dataset.
2. Calculate total revenue, average order value, total orders, and total units sold.
3. Analyze monthly revenue trends and identify high- and low-performing months.
4. Compare product categories, regions, and payment methods.
5. Identify top products by revenue and quantity sold.
6. Create visualizations and provide business recommendations.

## Key analyses

- Monthly revenue trend
- Revenue by product category
- Revenue by region
- Top 10 products by revenue
- Average order value by region
- Payment-method distribution

## How to run

```bash
pip install -r requirements.txt
python data/generate_data.py
python analysis/sales_analysis.py
```

Charts and KPI tables are saved in the `output/` folder.

## Files

- `data/generate_data.py`: creates the synthetic retail dataset
- `analysis/sales_analysis.py`: calculates KPIs and creates charts
- `sql/sales_queries.sql`: SQL queries for revenue, product, customer, and regional analysis
- `requirements.txt`: Python dependencies

## Portfolio value

This project demonstrates data cleaning, exploratory analysis, KPI calculation, SQL querying, visualization, and the ability to translate sales data into practical business insights.
